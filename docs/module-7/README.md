# Module 7 Documentation

Эта папка содержит техническую документацию по текущему состоянию проекта `six-cities` после задач модуля 7.

## Содержание

- [`getting-started.md`](./getting-started.md) — установка, запуск, скрипты, базовый troubleshooting.
- [`architecture.md`](./architecture.md) — архитектура приложения, роутинг, поток инициализации.
- [`state-and-redux.md`](./state-and-redux.md) — структура Redux state, actions, async thunks.
- [`api-and-auth.md`](./api-and-auth.md) — API-контракты, axios слой, токен, авторизация.
- [`pages-and-components.md`](./pages-and-components.md) — обзор ключевых страниц и компонентов.
- [`workflow.md`](./workflow.md) — практический процесс разработки и чек-лист перед PR.

## Быстрый старт

1. Перейдите в [`getting-started.md`](./getting-started.md) и запустите проект.
2. Для понимания структуры откройте [`architecture.md`](./architecture.md).
3. Для изменений в логике данных смотрите [`state-and-redux.md`](./state-and-redux.md) и [`api-and-auth.md`](./api-and-auth.md).

## Границы этой документации

- Документация описывает **актуальную реализацию** в `src/`.
- Статические макеты в `markup/` используются как UI-референс, но не как runtime-код.
- Учебные readme в корне и подпапках сохранены как исторические артефакты курса.
